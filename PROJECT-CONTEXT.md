# Guia Japão Incrível — Contexto do Projeto

## Objetivo
Criar uma versão totalmente independente do site:
https://www.guiajapaoincrivel.com

O objetivo é recriar o site exatamente igual visualmente usando:
- Next.js
- Tailwind CSS
- TypeScript

Sem usar Squarespace.
